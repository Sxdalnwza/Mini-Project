ตำแหน่งงานที่สนใจ: Backend Developer / Software Engineer

ปัจจุบันกำลังศึกษาชั้นปีที่ 2 สาขาวิชาวิศวกรรมซอฟต์แวร์ คณะวิทยาศาสตร์และเทคโนโลยี มหาวิทยาลัยราชภัฏนครปฐม มีความสนใจในการเขียนโค้ดเพื่อจัดการลอจิกของระบบ (System Logic) การออกแบบโครงสร้างฐานข้อมูล และการพัฒนาระบบหลังบ้านที่แก้ไขปัญหาให้ผู้ใช้งานได้จริง

จุดเด่นของฉัน (Highlights)

Backend & System Logic

ถนัดการเขียนโปรแกรมควบคุมเงื่อนไขการทำงานที่ซับซ้อน เช่น ลอจิกการตรวจสอบโควตาและการจัดสรรตารางเวลา รวมถึงพื้นฐานโครงสร้างข้อมูลและอัลกอริทึม

Database & Security

มีประสบการณ์เชื่อมต่อฐานข้อมูลทั้ง Google Sheets (Apps Script), MySQL และ Supabase เข้าใจหลักการทำระบบ CRUD และการป้องกันช่องโหว่ SQL Injection

System Analysis & Design

สามารถเก็บความต้องการจากผู้ใช้งานจริง มาจัดทำเอกสารข้อกำหนดซอฟต์แวร์ (SRS) พร้อมวาด Use Case Diagram และ Class Diagram เพื่อวางแผนก่อนเขียนโค้ดได้
