รายการผลงาน

รวบรวมผลงานแบบฝึกหัดในรายวิชาเรียน และโปรเจกต์การพัฒนาเว็บแอปพลิเคชันสำหรับใช้งานจริง

1. ระบบแสดงรายการสัตว์เลี้ยง

คำอธิบายผลงาน: เว็บไซต์แสดงข้อมูลสัตว์เลี้ยงแยกหมวดหมู่ พัฒนาขึ้นเพื่อฝึกสร้าง เว็บไซต์หลายหน้าและจัด Layout ด้วย CSS

หน้าที่รับผิดชอบ: ออกแบบโครงสร้างหน้าเว็บและจัด Layout ด้วย HTML และ CSS

เทคโนโลยีที่ใช้: HTML5, CSS และ GitHub Pages

ดูผลงาน

2. ระบบขอเวรเจ้าหน้าที่พยาบาล

คำอธิบายผลงาน: เว็บแอปพลิเคชันสำหรับให้เจ้าหน้าที่ พยาบาลส่งคำขอเวรและวันหยุด พร้อมตรวจสอบโควตาและสถานะคำขอ

หน้าที่รับผิดชอบ: พัฒนาระบบทั้งหมดด้วยตนเอง ตั้งแต่การออกแบบระบบ พัฒนาส่วนติดต่อผู้ใช้ ระบบตรวจสอบโควตา และการเชื่อมต่อฐานข้อมูล

เทคโนโลยีที่ใช้: HTML5, JavaScript, Tailwind CSS, SweetAlert2, Google Apps Script และ Google Sheets

3. ระบบขอเวรและจัดตารางเวรเจ้าหน้าที่พยาบาล

คำอธิบายผลงาน: ระบบบริหารจัดการตารางเวรรายเดือน แสดงภาพรวมเวรของเจ้าหน้าที่ พร้อมตรวจสอบเงื่อนไขการจัดเวร

หน้าที่รับผิดชอบ: พัฒนาระบบทั้งหมดด้วยตนเอง ตั้งแต่การออกแบบระบบ พัฒนาอัลกอริทึมจัดตารางเวร ระบบส่งออกข้อมูล และการเชื่อมต่อฐานข้อมูล

เทคโนโลยีที่ใช้: HTML5, JavaScript, Tailwind CSS, Google Apps Script, Supabase, SheetJS และ jsPDF
